Visual components

Each function names a visible terminal component; semantic meaning is selected with flags.

ASCII heading component

moma-header

Stable

Three-line Pagga text for a prominent script or workflow identity, with one blank line above, two below, and no left indent by default.

moma-header "TEXT" [--color color] [--margin-top number] [--margin-bottom number] [--margin-left number] [--no-color]

Input component

moma-input

Interactive

Display or read a field with placeholders, validation, secret masking, and one blank line below each interactive value.

moma-input --title "Project name" --read --required [--secret] [--mask symbol] [--default value] [--width number] [--max-width number]

Command interface

The standalone file exposes every library function as a command and keeps documentation previews in the same entrypoint.

Component commandsCLI

Call any visual component without sourcing the library.

moma title | title-sub | section | msg | msg-simple | list | box | prompt | label | input | select | multi-select | rabbit
Helper commandsCLI

Run confirmation, spinner, executable checks, and release operations.

moma confirm | spinner | command-check | version | update
Color themesCLI

Load themes from ~/.config/momaui/moma.confg, list them, or select one for a command.

moma themes | moma --theme NAME msg "Ready"
Documentation commandsCLI

Open terminal, Markdown, web, or usage documentation.

moma preview [md|web] | help
